Être informé

Pourquoi « tout le monde est propriétaire » n'est pas un slogan chez UQ.

Parce que l'architecture le rend vrai. Dans un cloud centralisé classique, tes fichiers vivent sur le serveur de quelqu'un d'autre. Ici, ils vivent sur les appareils chiffrés des utilisateurs — y compris le tien. UQ n'a pas de backdoor, pas de copie maîtresse, pas de salle serveur où tes données dorment. La seule chose qui nous appartient, c'est le code qui fait tourner le réseau. Et ce code, la communauté le fait évoluer avec nous.
